# TrackZen — Intelligent Railway Block Planning (RailSync SIH 2026)

A full-stack, AI-powered railway maintenance block planning engine submitted for **Smart India Hackathon (SIH) 2026**.

## 🌟 Features & Stack
- **Frontend Dashboard**: React + Vite + Tailwind CSS + Leaflet (Interactive Corridor Digital Twin & Calendar Schedule)
- **Backend API**: FastAPI (Python 3.10) with automatic Swagger Docs (`/docs`) & ReDoc (`/redoc`)
- **Optimization & ML**: XGBoost + SHAP (Priority Engine), OR-Tools CP-SAT (Combinatorial Scheduler), NetworkX (Corridor Network Impact)

---

## ⚡ 1-Click Local Run (Windows)
- **Unified Production Server**: Double-click `START_LOCAL.bat` — opens `http://localhost:8000` (serves both React UI + API + Swagger Docs).
- **Dual Development Server**: Double-click `START_DEV.bat` — opens hot-reloading dev server on `http://localhost:5173`.
